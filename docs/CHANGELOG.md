# 更新说明

## v0.5.2（2026-06-18）

### Tag 归档 / 变更列表

- 大版本目录文件过多时，**自动改为添加 `production/dist`、`prod/dist` 等 dist 目录**
- 嵌套未版本控制目录在变更列表中**展开显示子项**，便于勾选 dist 产物
- `svn add` 支持 **`--parents` / `--force`**，可添加深层 dist 路径并跳过已受控文件

### 远程 URL

- **复制远程链接**、创建分支/标签、切换分支、合并、检出等处，将 `%E4%B8%AD` 等编码**解码为可读中文**

---

## v0.5.1（2026-06-15）

### 仓库浏览器

- 右键菜单与工具栏新增 **复制远程链接**
- 新增 **返回上一级**（工具栏与详情顶栏）
- 目录列表显示 **提交时间**
- 右侧目录区背景色比左侧边栏略浅，层次更清晰

### 分支 / 标签

- 适配企业仓库 `XX_SourceCodes/03_Tag/` 目录布局（如 `05_SourceCodes/03_Tag/项目/版本号`）
- **目标 URL** 可手动编辑；标签名称误粘贴完整 URL 时自动提取版本号
- 修复 Tag 创建时 `MKCOL forbidden` 错误（改为先 copy、仅在父目录缺失时再 mkdir）
- 目标 URL 仅填到 Tag 项目目录时，自动追加版本号

### 变更列表

- **允许提交 `dist` 构建产物**，支持 Tag 归档场景（不再默认拦截 dist 目录）
- 大批量「不宜直接提交」提示改为 **汇总显示**，避免弹窗过长导致界面卡死
- 操作失败提示改为 **可滚动面板**，便于查看与关闭

### 其他

- 修复 GUI 启动时 **中文工作副本路径** 无法识别的问题
- 主窗口侧边栏布局优化（HSplitView）

---

## v0.5.0-beta

首个公测包，包含 M3 核心功能：

- 冲突解决（三方合并、快捷 resolve）
- 分支与合并（创建分支/标签、Switch、Merge 向导、mergeinfo）
- 仓库浏览器（懒加载目录树、远程 CRUD、文件预览、从此处检出）
- 大目录 FSEvents 增量刷新、外部 diff 工具、日志本地缓存、并排 diff

安装说明见 [beta 安装说明](./beta安装说明.md)。
