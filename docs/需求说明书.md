# easySvn 需求说明书

- **产品名称**：easySvn
- **产品定位**：macOS 平台原生 SVN 图形化客户端
- **对标产品**：TortoiseSVN（Windows）、Cornerstone、Versions
- **文档版本**：v0.1（草案）
- **日期**：2026-06-12

---

## 1. 项目背景与目标

### 1.1 背景

- Windows 平台的 TortoiseSVN 功能完善、深度集成资源管理器，是 SVN 用户的事实标准；macOS 平台缺少同等体验的免费/现代化工具。
- 现有 macOS 客户端（Cornerstone、Versions 等）收费较高、更新缓慢，且 UI 风格陈旧；命令行 `svn` 对非开发岗位（美术、策划、文档人员）门槛高。

### 1.2 产品目标

1. 提供覆盖日常 SVN 工作流的图形化操作，**零命令行**即可完成检出、更新、提交、分支、合并等操作。
2. 提供接近 TortoiseSVN 的体验：状态一目了然、右键即用、Finder 图标徽章。
3. 原生 macOS 体验：SwiftUI 界面、深色模式、钥匙串、通知中心。

### 1.3 目标用户

| 用户群体 | 典型场景 | 关键诉求 |
|---|---|---|
| 开发人员 | 代码提交、看 diff、分支合并 | 高效、diff 准确、日志检索快 |
| 美术/策划 | 提交二进制资源（PSD、贴图） | 简单易懂、文件锁、缩略图预览 |
| 文档/运营 | 文档版本管理 | 零学习成本、防误操作 |

### 1.4 运行环境

- macOS 13.0（Ventura）及以上，支持 Apple Silicon 与 Intel
- 兼容 SVN 1.10+ 服务端与工作副本格式（以内置/系统 `svn` 客户端版本为准）
- 协议支持：`http(s)://`、`svn://`、`svn+ssh://`、`file://`

## 2. 总体功能架构

```
easySvn
├── 主应用（App）
│   ├── 工作副本管理（侧边栏书签）
│   ├── 状态视图（工作副本变更列表）
│   ├── 提交 / 更新 / 还原 / 清理
│   ├── 日志查看器（Log）
│   ├── 差异比较器（Diff）与冲突解决（Merge）
│   ├── 分支 / 标签 / 切换 / 合并
│   ├── 仓库浏览器（Repo Browser）
│   ├── 锁定 / 属性 / 补丁 / 导出
│   └── 设置（认证、外部工具、通用）
├── Finder 扩展（Finder Sync Extension）
│   ├── 文件状态图标徽章
│   └── 右键快捷菜单
└── SVN 引擎层（封装 svn 命令行，解析 --xml 输出）
```

## 3. 功能需求

> 优先级定义：P0 = MVP 必备；P1 = 第二阶段；P2 = 增强功能。

### 3.1 工作副本管理（P0）

| 编号 | 需求 | 说明 |
|---|---|---|
| WC-1 | 添加工作副本 | 选择本地目录添加为书签；自动识别是否为有效工作副本 |
| WC-2 | 检出（Checkout） | 输入仓库 URL，选择本地目录、版本号、检出深度；显示进度与可取消 |
| WC-3 | 侧边栏列表 | 展示所有工作副本，显示名称、分支路径、是否有本地修改的角标 |
| WC-4 | 移除书签 | 仅从列表移除，不删除本地文件 |
| WC-5 | 工作副本信息 | 显示 URL、版本号、最后提交信息（svn info） |

### 3.2 状态视图与基本操作（P0）

| 编号 | 需求 | 说明 |
|---|---|---|
| ST-1 | 变更列表 | 展示已修改/新增/删除/缺失/冲突/未版本控制/忽略的文件，带颜色与图标区分 |
| ST-2 | 过滤与搜索 | 按状态类型过滤、按文件名搜索 |
| ST-3 | 刷新 | 手动刷新 + 文件系统监听（FSEvents）自动刷新 |
| ST-4 | Update | 整体或选中路径更新；支持更新到指定版本；结果摘要（新增/合并/冲突数） |
| ST-5 | Commit | 勾选文件 + 填写日志提交；支持最近日志历史复用；提交前可逐文件看 diff；空日志告警 |
| ST-6 | Add / Delete | 将未版本控制文件加入版本控制；删除受控文件 |
| ST-7 | Revert | 还原选中文件的本地修改，二次确认；支持递归还原 |
| ST-8 | Rename / Move | 受版本控制的重命名与移动（svn mv） |
| ST-9 | Cleanup | 清理工作副本锁定状态 |
| ST-10 | 忽略管理 | 右键将文件/扩展名加入 svn:ignore |

### 3.3 差异比较（P0）

| 编号 | 需求 | 说明 |
|---|---|---|
| DF-1 | 文本 Diff | 内置双栏对比视图，语法高亮、行内差异高亮、变更块导航 |
| DF-2 | 比较对象 | 工作副本 vs BASE；工作副本 vs 任意版本；任意两版本之间 |
| DF-3 | 图片对比 | 常见图片格式并排预览（P1） |
| DF-4 | 外部工具 | 可配置 Beyond Compare、Kaleidoscope、FileMerge 等外部 diff/merge 工具（P1） |

### 3.4 日志查看器（P0）

| 编号 | 需求 | 说明 |
|---|---|---|
| LG-1 | 版本列表 | 版本号、作者、日期、提交信息；分页/增量加载 |
| LG-2 | 变更文件 | 选中版本显示其变更文件列表（A/M/D/R），双击看 diff |
| LG-3 | 过滤 | 按作者、日期范围、关键字过滤 |
| LG-4 | 版本操作 | 从日志发起：更新到此版本、还原此版本的修改（reverse merge）、导出文件、复制版本号 |
| LG-5 | 日志缓存 | 本地缓存已拉取日志，加速二次浏览（P1） |

### 3.5 冲突解决（P1）

| 编号 | 需求 | 说明 |
|---|---|---|
| CF-1 | 冲突列表 | 更新/合并后高亮冲突文件 |
| CF-2 | 三方合并视图 | mine / theirs / base 三栏 + 结果编辑区，逐块选择采用方 |
| CF-3 | 快捷解决 | 一键"采用我的/采用对方"；标记已解决（resolved） |
| CF-4 | 树冲突 | 展示树冲突信息并提供解决选项 |

### 3.6 分支与合并（P1）

| 编号 | 需求 | 说明 |
|---|---|---|
| BR-1 | 创建分支/标签 | 基于工作副本或仓库 URL 复制到目标路径，附提交日志 |
| BR-2 | Switch | 切换工作副本到其他分支 URL，提示未提交修改 |
| BR-3 | Merge | 区间合并（指定版本范围）与分支自动合并；合并前 dry-run 预览 |
| BR-4 | Merge 追踪 | 显示已合并/未合并版本（mergeinfo） |

### 3.7 仓库浏览器（P1）

| 编号 | 需求 | 说明 |
|---|---|---|
| RB-1 | 目录树浏览 | 不检出直接浏览仓库结构，支持指定版本浏览 |
| RB-2 | 远程操作 | 在仓库端新建文件夹、删除、重命名、移动（直接产生提交） |
| RB-3 | 文件查看 | 查看远程文件内容、查看日志、导出 |
| RB-4 | 从此处检出 | 任意目录右键发起 Checkout |

### 3.8 Finder 集成（P1）

| 编号 | 需求 | 说明 |
|---|---|---|
| FN-1 | 图标徽章 | 受控目录内文件显示状态徽章：正常/修改/新增/冲突/忽略/锁定 |
| FN-2 | 右键菜单 | Finder 中右键提供：Update、Commit、Log、Diff、Revert、在 easySvn 中打开 |
| FN-3 | 性能 | 大目录（≥10 万文件）下徽章查询不阻塞 Finder |

### 3.9 锁定与属性（P2）

| 编号 | 需求 | 说明 |
|---|---|---|
| LK-1 | Lock / Unlock | 加锁（附说明）/解锁/强制解锁；列表显示锁持有者 |
| LK-2 | needs-lock | 识别并提示 svn:needs-lock 文件 |
| PR-1 | 属性编辑 | 查看/编辑常用 SVN 属性（ignore、externals、eol-style、keywords） |

### 3.10 其他功能（P2）

| 编号 | 需求 | 说明 |
|---|---|---|
| OT-1 | Blame | 逐行显示最后修改版本与作者，点击行跳转日志 |
| OT-2 | Patch | 生成统一 diff 补丁、应用补丁 |
| OT-3 | Export | 导出不含 .svn 的干净副本 |
| OT-4 | Relocate | 仓库地址变更迁移 |
| OT-5 | 菜单栏入口 | 菜单栏图标显示各工作副本状态摘要，快捷发起更新/提交 |

### 3.11 认证与设置（P0）

| 编号 | 需求 | 说明 |
|---|---|---|
| AU-1 | 认证方式 | 用户名密码、SSH 密钥（svn+ssh）、SSL 客户端证书 |

| SE-3 | 全局忽略 | 全局忽略模式（global-ignores） |

## 4. 非功能需求

| 类别 | 要求 |
|---|---|
| 性能 | 1 万文件的工作副本状态扫描 ≤ 3s；日志加载每页（100 条）≤ 2s；UI 不因 SVN 操作卡顿（全部异步） |
| 可靠性 | 任何操作失败给出可读的错误信息与建议；长操作可取消；崩溃不损坏工作副本 |
| 安全 | 凭据仅存 Keychain，不落明文；不上传任何用户数据 |
| 易用性 | 危险操作（Revert、强制解锁、远程删除）二次确认；常用操作有快捷键 |
| 国际化 | 简体中文、英文 |
| 分发 | 公证（Notarization）+ DMG 分发；Finder 扩展需 App Sandbox 适配 |

## 5. 技术方案（建议）

| 层 | 选型 | 说明 |
|---|---|---|
| UI | SwiftUI（局部 AppKit 补充，如 NSTextView 实现 diff 视图） | 原生体验、开发效率高 |
| SVN 引擎 | 封装 `svn` 命令行，解析 `--xml` 输出（status/info/log/list 等） | 避免链接 SVN C 库的复杂度与许可问题；首选检测系统/Homebrew svn，必要时随 App 捆绑 |
| 并发 | Swift Concurrency（async/await） | 所有 SVN 调用异步化 |
| Finder 集成 | FinderSync Extension + App Group/XPC 与主程序共享状态缓存 | 徽章与右键菜单 |
| 数据持久化 | 书签与设置用 UserDefaults/JSON；日志缓存用 SQLite | 轻量 |
| 凭据 | Security.framework（Keychain） | |

**关键技术风险**：
1. Finder Sync 扩展在沙盒下访问任意路径的权限处理（需要用户授权目录访问）。
2. 大工作副本的状态扫描性能（依赖 `svn status` 本身性能 + 增量缓存）。
3. `svn+ssh` 的交互式认证在 GUI 下的处理（需配置 SSH agent / 免交互）。

## 6. 验收标准（MVP）

1. 能完成完整工作流：Checkout → 修改 → 查看状态/Diff → Commit → 查看 Log → Update → Revert。
2. 密码保存在 Keychain，二次操作不再询问。
3. 所有操作期间 UI 可响应、可取消。
4. 错误场景（网络断开、认证失败、工作副本锁定）均有明确提示。
