# easySvn v0.5.1 安装说明

## 环境要求

- **macOS 13** 或更高版本
- **Apple 芯片（M 系列）** Mac（当前 beta 包为 arm64 构建）

## 安装前准备

本应用依赖系统 Subversion 命令行工具，请先安装：

```bash
brew install subversion
```

安装后可在终端验证：

```bash
svn --version
```

## 安装方式

分发包提供 **DMG** 与 **ZIP** 两种格式，任选其一即可。

### 方式一：DMG（推荐）

1. 双击 `easySvn-0.5.1-macos-arm64.dmg` 挂载磁盘镜像
2. 将窗口中的 `easySvn.app` 拖入 **Applications**（应用程序）文件夹
3. 弹出磁盘镜像（将桌面上的 easySvn 磁盘拖入废纸篓，或右键推出）

### 方式二：ZIP

1. 解压 `easySvn-0.5.1-macos-arm64.zip`
2. 将 `easySvn.app` 拖入「应用程序」文件夹

## 首次打开

本 beta 为内部试用包，未经 Apple 公证。首次启动时请按以下方式操作：

1. **不要直接双击**
2. 在「应用程序」中找到 `easySvn.app`，**右键 →「打开」**
3. 在弹窗中再次点击「打开」

若仍被系统拦截：

1. 打开 **系统设置 → 隐私与安全性**
2. 在安全性区域找到 easySvn 相关提示
3. 点击 **「仍要打开」**

确认一次后，之后可正常双击启动。

## 开始使用

1. 启动 easySvn
2. 点击左下角 **「检出…」** 从远程仓库检出，或 **「添加工作副本」** 选择本地已有目录
3. 连接需认证的服务器时，按提示输入凭据（可选择保存到钥匙串）

## 常见问题

**提示找不到 svn 命令行工具**

请先执行 `brew install subversion`，并确认 `svn --version` 能正常输出。

**提示无法打开，因为无法验证开发者**

属正常现象，请按上文「首次打开」步骤，使用右键「打开」。

**Intel Mac 能否使用**

当前 beta 仅提供 Apple 芯片（arm64）版本，Intel Mac 暂不支持。
