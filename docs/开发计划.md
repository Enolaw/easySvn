# easySvn 开发计划

- **关联文档**：[需求说明书](./需求说明书.md)
- **总体节奏**：4 个里程碑（M1–M4），约 16–20 周（按 1 人全职估算，可按人力线性调整）
- **日期**：2026-06-12

---

## 1. 里程碑总览

| 里程碑 | 内容 | 周期 | 产出 |
|---|---|---|---|
| M1 | 基础框架 + SVN 引擎层 | 3 周 | 可运行的 App 骨架，引擎层单测通过 |
| M2 | MVP 核心功能（P0） | 6 周 | 内部可用版本 v0.1（alpha） |

## 2. M1：基础框架与 SVN 引擎层（第 1–3 周）

> 目标：打牢地基。引擎层是全部功能的依赖，必须优先且配齐单元测试。

### 第 1 周：工程搭建
- [ ] 创建 Xcode 工程（SwiftUI App + 单元测试 target），配置 SwiftLint/SwiftFormat
- [ ] 确定模块划分：`SvnKit`（引擎）、`Core`（模型/存储）、`UI`
- [ ] svn 可执行文件探测策略（系统 / Homebrew / 捆绑），版本检测
- [ ] 进程执行器：异步运行命令、流式读取输出、超时与取消

### 第 2–3 周：SVN 引擎层（SvnKit）
- [ ] XML 解析：`svn status / info / log / list / diff --xml` → Swift 模型
- [ ] 封装命令：checkout、update、commit、add、delete、revert、move、cleanup、cat、export
- [ ] 认证处理：`--username/--password` 注入、Keychain 读写、证书信任交互
- [ ] 错误归一化：将 svn 错误码/stderr 映射为可读错误类型
- [ ] **单元测试**：基于本地 `file://` 测试仓库（svnadmin create）覆盖以上命令

**验收**：命令行层全部接口在测试仓库上通过 CI 单测。

## 3. M2：MVP 核心功能（第 4–9 周）

> 目标：完成 P0 需求，跑通"检出→修改→提交"全流程，产出 v0.1 alpha。

### 第 5–6 周：状态视图与基本操作（ST-1~10）

- [ ] FSEvents 监听自动刷新 + 手动刷新
- [ ] Update（含到指定版本）、结果摘要
- [ ] Commit 面板（勾选、日志、最近日志历史、空日志告警）
- [ ] Add / Delete / Revert（二次确认）/ Rename / Cleanup / 忽略管理

### 第 7 周：差异比较（DF-1、DF-2）

### 第 8 周：日志查看器（LG-1~4）
- [ ] 版本列表 + 增量加载
- [ ] 变更文件列表、双击 diff
- [ ] 作者/日期/关键字过滤
- [ ] 版本右键操作（更新到此版本、reverse merge、导出、复制版本号）

### 第 9 周：认证设置 + 集成联调（AU-1~3、SE-1）
- [ ] 认证弹窗（密码/证书信任），Keychain 集成
- [ ] 设置页（语言、主题）
- [ ] 全流程联调 + 修 bug，打 **v0.1 alpha** 包内部试用

**验收**：达到需求说明书第 6 节 MVP 验收标准。

## 4. M3：进阶功能（第 10–14 周）

> 目标：完成 P1 需求，产出 v0.5 beta 对外公测。

### 第 10 周：冲突解决（CF-1~4）
- [ ] 冲突文件标识与列表
- [ ] 三方合并视图（mine/theirs/base + 结果区）
- [ ] 一键采用、标记 resolved、树冲突处理

### 第 11 周：分支与合并（BR-1~4）
- [ ] 创建分支/标签、Switch
- [ ] Merge 向导（区间合并/分支合并、dry-run 预览）
- [ ] mergeinfo 展示

### 第 12 周：仓库浏览器（RB-1~4）
- [ ] 远程目录树（懒加载、指定版本）
- [ ] 远程新建/删除/重命名/移动
- [ ] 从此处检出、查看远程文件与日志

### 第 13–14 周：Finder 集成（FN-1~3）+ 体验补全
- [ ] FinderSync 扩展：状态徽章（App Group 共享状态缓存 + XPC）
- [ ] Finder 右键菜单（Update/Commit/Log/Diff/在 easySvn 打开）

## 6. 测试策略

| 层级 | 方式 | 覆盖 |
|---|---|---|
| 单元测试 | XCTest + 本地 `file://` 测试仓库（脚本自动 svnadmin create + 造数据） | SvnKit 全部命令与 XML 解析 |
| 集成测试 | 脚本化场景：检出→改→提交→冲突→合并 | 核心工作流 |
| UI 测试 | XCUITest 覆盖关键路径（检出、提交、日志） | 冒烟 |
| 手工测试 | 真实服务器（http/https/svn+ssh）、大仓库、弱网/断网 | 兼容性与异常 |
| 性能测试 | 1 万 / 10 万文件工作副本基准 | 状态扫描、徽章响应 |

CI：GitHub Actions（macOS runner）跑 build + 单测 + lint，每个里程碑出归档包。

## 7. 风险清单

| 风险 | 影响 | 应对 |
|---|---|---|
| Finder Sync 沙盒权限与性能 | 徽章功能不可用或卡 Finder | 提前在 M1 末做技术验证（spike）；准备降级方案 |
| svn 命令行版本差异（1.10/1.14 输出差异） | 解析失败 | 启动时检测版本，解析层做兼容；CI 矩阵覆盖两个版本 |
| svn+ssh 交互式认证 | 该协议用户无法使用 | 文档引导配置 ssh-agent；后续支持内置 key 选择 |
| Diff 视图大文件性能 | 卡顿 | 虚拟化渲染、超大文件回退为只读分页 |
| 个人开发周期偏差 | 延期 | 每里程碑末复盘，P2 功能可裁剪 |
